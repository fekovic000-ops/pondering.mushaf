Pondering Mushaf - offline app

1. Unzip this folder. Deploy the whole folder (or the zip) on Netlify Drop or Vercel Drop.
2. Open the web address in Safari. Wait a few seconds the first time. The page shows right away and the Quran data loads after it.
3. Tap Share, then Add to Home Screen. Open the app once with internet so it saves itself. After that it works in airplane mode.
4. Before you switch, back up old notes: old link > Backup > Create backup. In the new app: Backup > paste > Restore.
